# 世界切片选题日报 · 首版

Owner：动动。生命周期：持续使用的个人创作工具。源代码归属本项目；运行数据与凭据不进入 Git。

目标：从最新新闻与热榜中挑出适合历史人物、科普和社会现象的视频切口，最多生成三张可展开选题卡，支持待拍、跳过、撤销、来源追溯与失败进度。

采用 AIHOT 框架的 PostgreSQL、任务队列、模型回执与限额、API、React Router SSR 和管理后台。新增功能集中在 `modules/creator-daily/`。首页重定向到选题页；默认的海外 AI 示例源不启用。

首版信源：60s 每日新闻、抖音热榜、知乎热榜、AI HOT 精选、NASA、ScienceDaily。每个信源独立记录日期、数量与失败原因；聚合摘要只作为创作线索。B站接口在接入探针返回500，本轮不作为正常源。

工作流：并行读取公开源 → 逐条保存线索 → 在各来源的有界候选里初筛 → 逐题生成最多三张短卡片 → 校验引用ID、完整表达与重复事件 → 原子保存日报。网页GET不触发模型；显式更新或每日北京时间10点任务才发起生成。默认每日最多12次模型请求；结果未知不自动重发，已收到但结构无效的单卡最多校订一次。缓存沿用框架回执。先生成选题，剧本制作不在首版自动执行。

真实模型验证发现：整批长稿两次达到240秒超时；小JSON探针2.6秒返回；初筛输出预算1900时有1890用于思考，正式JSON被截断。改为有界初筛与逐题短稿后，首份三题日报291.9秒保存；成稿检查发现第三题标题和切口是半句，已加入真实失败回归，并用独立单卡接口51秒校订。没有把超时请求标成未发出，也没有重发结果未知的逻辑请求。

验收：公开源真实读取；本地GLM结构化输出真实调用；生产前端构建与启动；桌面、手机、深色模式；收藏、撤销、跨站写入拒绝；源失败、模型失败保留上一期；刷新阅读不增加模型调用。

本机运行：127.0.0.1:13000（网页）、13001（API）、55433（独立PostgreSQL）。复用现有PostgreSQL程序，不使用Sub2API的数据库。模型密钥由本机加密凭据解密到API/worker进程环境，网页进程不接收。

新增说明文案：无。页面正文为选题内容；“开拍前核实”用于防止把候选摘要直接当作已核实脚本。运行状态、错误、空状态为功能反馈。
